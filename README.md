## Cybersecurity and ethical hacking

I work on offensive security with a defensive goal: find the weak spot before someone else does, then fix it.

- **IoT and embedded security:** firmware analysis, hardware interfaces, wireless attack surface
- **Web application security:** testing against the OWASP Top 10, auth and session flaws, API abuse
- **Network recon and traffic analysis:** mapping, service enumeration, packet-level inspection
- **Secure by design:** the same mindset goes into every product we ship at Vexocore
